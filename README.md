# antigravity-threat-scanner
# 🛡️ Sentinel Threat & Phishing Inspector

A lightweight, browser-based security tool built with HTML, CSS, and vanilla JavaScript. 

## Features
- **Batch Text Regex Extractor**: Automatically parses and deduplicates URLs from raw emails, SMS, or plain text while filtering out JavaScript properties and code syntax.
- **Heuristic Threat Engine**: Flags high-risk top-level domains (`.shop`, `.xyz`), brand impersonation in subdomains, excessive hyphenation, and raw IP addresses.
- **Google Safe Browsing API Integration**: Optional live threat lookup against official malware and phishing databases.
- **Interactive Terminal UI**: Real-time audit logs and risk breakdown panel.
